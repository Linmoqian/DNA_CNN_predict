# 启动子与基因表达调控

## 一、启动子的结构

启动子（Promoter）是位于基因 5' 端上游的 DNA 序列，能够活化 RNA 聚合酶并决定转录起始的特异性。按与转录起始位点（TSS）的距离分为三个区域：

```
5' --[远端启动子]--[近端启动子]--[核心启动子]--> TSS --> 结构基因 --> 3'
        |                |               |
   远程调控元件      基础调控元件     转录起始复合物
```

| 区域 | 位置 | 关键元件 | 功能 |
|------|------|----------|------|
| 核心启动子 | TSS 上游 -35bp 内 | TATA box、起始子(Inr) | 转录起始复合物组装 |
| 近端启动子 | TSS 上游 -250bp 内 | CAAT box、GC box | 转录效率调控 |
| 远端启动子 | 更上游 | 特定 TF 结合位点 | 精细调控 |

本项目输入为 TSS +/-10000bp，覆盖以上所有区域及部分近端增强子。

## 二、关键调控元件

### 2.1 TATA Box
- 保守序列：5'-TATA(A/T)A(A/T)-3'
- 位置：TSS 上游约 -25 ~ -35 bp
- 结合蛋白：TBP（TATA 结合蛋白，TFIID 亚基）
- 功能：指导 RNA 聚合酶 II 定位转录起始位点
- 特点：并非所有基因都有，两侧常被 GC 富集序列包围

### 2.2 CAAT Box
- 保守序列：5'-GGCCAATCT-3'
- 位置：TSS 上游约 -75 ~ -80 bp
- 结合蛋白：NF-Y（CBF）
- 功能：调控转录频率/效率，决定启动子强度
- 特点：双向均可发挥作用

### 2.3 GC Box
- 保守序列：5'-GGGCGG-3'
- 位置：TSS 上游约 -40 ~ -110 bp
- 结合蛋白：SP1
- 功能：增强基础转录活性；无 TATA box 的启动子中扮演替代角色
- 特点：常以多拷贝存在，常见于管家基因

### 2.4 CpG 岛
- GC 含量高、CpG 二核苷酸富集区域，长度通常 500-2000bp
- 约 70% 人类基因启动子含 CpG 岛
- 位置：TSS 附近约 -1.5kb 到 +0.5kb
- 低甲基化 = 活跃转录；高甲基化 = 基因沉默

### 2.5 三种核心元件对比

| 对比项 | TATA Box | CAAT Box | GC Box |
|--------|----------|----------|--------|
| 保守序列 | TATA(A/T)A(A/T) | GGCCAATCT | GGGCGG |
| 距TSS位置 | -25 ~ -35 bp | -75 ~ -80 bp | -40 ~ -110 bp |
| 结合TF | TBP（TFIID亚基） | NF-Y（CBF） | SP1 |
| 主要功能 | 确定转录起始位置 | 调控转录频率 | 增强基础转录 |

## 三、增强子远程调控

增强子（Enhancer）是远程增强基因转录的顺式调控元件。关键特性：
- 在 TSS 5' 或 3' 侧均能起作用
- 相对启动子任一方向均能起作用
- 作用距离可远可近

### 调控机制：染色质环化
增强子通过染色质三维折叠/环化与启动子发生物理接触：
- **Cohesin 复合体**：通过"环挤出"将增强子和启动子拉近
- **Mediator 复合物**：连接增强子与启动子处 RNA 聚合酶
- **CTCF 蛋白**：划分拓扑关联域（TAD），绝缘子功能

### +/-10000bp 范围内的调控元件

| 调控元件 | 典型位置 | 功能 |
|---------|---------|------|
| 核心启动子元件 | TSS -35bp 内 | 转录起始复合物组装 |
| 近端调控元件 | TSS -40 ~ -250bp | 转录效率调控 |
| CpG 岛 | TSS -1.5kb ~ +0.5kb | 表观遗传调控 |
| 近端增强子 | TSS 上下游数 kb | 转录激活 |
| 沉默子 | TSS 上下游数 kb | 抑制基因表达 |
| 绝缘子 | 特定位置，CTCF 结合 | 划分调控域边界 |

## 四、基因表达调控的层级机制

### 4.1 染色质层面（表观遗传）
- **DNA 甲基化**：CpG 位点甲基化通常抑制转录
- **组蛋白修饰**：
  - H3K4me3：活跃启动子标记
  - H3K27ac：活跃增强子/启动子标记
  - H3K4me1：增强子标记
  - H3K27me3：Polycomb 抑制标记
  - H3K9me3：异染色质标记
- **染色质重塑**：SWI/SNF 等复合物调节染色质可及性
- **基因组三维结构**：TAD、染色质环、A/B compartment

### 4.2 转录层面
- 转录因子结合启动子/增强子上的特定 motif
- RNA 聚合酶 II + 通用转录因子组成基础转录机器
- 增强子-启动子通过染色质环化实现远程激活

### 4.3 转录后层面
- RNA 剪接（可变剪接产生不同 mRNA 异构体）
- mRNA 稳定性调控（poly(A) 尾长度、UTR 结合蛋白）
- miRNA/lncRNA 调控
- 核质运输调控

### 4.4 翻译及翻译后层面
- 翻译效率调控（mTOR 通路、eIF 因子）
- 蛋白质修饰与降解

> **与本项目的关系**：CNN 模型用 DNA 序列主要捕获转录层面的调控信息（启动子元件、TF 结合位点），halflife 8 维特征间接反映转录后层面信息。

## 五、GM12878 细胞系

| 属性 | 详情 |
|------|------|
| 细胞类型 | B 淋巴母细胞样细胞系 |
| 来源 | HapMap 计划，北欧和西欧血统女性 |
| 转化方式 | EB 病毒转化 |
| ENCODE 分级 | Tier 1（最高优先级） |

### 为什么常用于基因表达研究
1. **数据最丰富**：ENCODE Tier 1，拥有 RNA-seq、ChIP-seq、Hi-C、ATAC-seq、DNase-seq、WGBS 等全面多组学数据
2. **B 细胞免疫学重要性**：研究免疫球蛋白基因调控、B 细胞分化
3. **疾病模型**：白血病、淋巴瘤等血液肿瘤研究模型
4. **标准参考**：超过 148 篇论文引用，广泛认可的基因组学标准

### 与本项目的关联
- 模型学到的是 B 淋巴细胞中特异性的调控模式
- B 细胞特异性 TF（PAX5、EBF1、E2A、IRF4、SPI1 等）的结合位点可能对预测有重要贡献
- 模型泛化能力可能受限于 B 细胞系的调控特征
