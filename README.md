# DNA_CNN_predict

大一上做的一个基于CNN加注意力机制的DNA预测表达模型。10次训练后，准确率81%。

## 数据集

数据下载：http://www.aisccc.cn/database/data-details?id=121

## 目录结构

```
DNA_CNN_predict/
├── data/          # 数据文件（h5 文件需手动解压到此处）
├── docs/          # 文档
├── model/         # 模型定义
├── script/        # 训练/评估脚本
└── utils/         # 工具函数
```
